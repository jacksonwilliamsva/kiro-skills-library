# Grill Me

Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one.

## Rules

- **One question at a time.** Do not batch questions.
- **Provide your recommended answer** with each question so I can accept, reject, or refine it.
- **Explore the codebase first.** If a question can be answered by reading code, read the code instead of asking me.
- **No spec output.** Do not produce a spec, design doc, or writing-plans handoff. This is interrogation, not documentation.
- **Stay focused.** When all branches are resolved and we have shared understanding, summarize the decisions made and stop.

## When to use grill-me vs brainstorming

| grill-me | brainstorming |
|---|---|
| Stress-test a decision or plan you already have | Design a feature from scratch |
| Fast, conversational, no artifacts | Produces specs, design docs, visual companions |
| "I think we should do X — poke holes" | "We need to build X — help me figure out how" |
